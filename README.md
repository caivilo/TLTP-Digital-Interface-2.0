# The-Lesbian-Taxonomy-Archive
The Lesbian Taxonomy Project (TLTP) Digital Archive Interface is the online, interactive search database for an ongoing digital humanities project centered on the cultural, societal taxonomy related primarily to lesbians (and later more broadly sapphic identities). It works as an OPAC (Online Public Access Catalog) for lesbian history.

It attempts to put a more retro-cyber punk twist on traditional archiving OPACs.
